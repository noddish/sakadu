# 사카두 디자인 규칙

사카두 화면(Windows·macOS)을 그릴 때 따르는 기준이다. 값은 공통 코드(`src/ui`, `src/palette.rs`)에 이름 붙은 상수로 두고, 그리기 코드에는 숫자를 직접 쓰지 않는다. 이 문서의 단계 밖 값을 써야 하면 까닭을 주석으로 남긴다.

- 상태: 초안 (2026-11-25). 지금 코드의 값을 모아 단계로 묶었다. 아직 코드는 이 문서를 따르지 않는다(맨 아래 '지금 값과의 차이').
- 단위: 화면 좌표(DIP, 맥은 point). 1 = 96dpi의 1px.

---

## 1. 원칙

1. **바탕은 조용히, 내용이 주인공.** 창·칸·단추는 무채색 단계로만 구분한다. 색은 강조 색 한 가지와, 의미가 있는 곳(선택, 상태)에만 쓴다.
2. **화면마다 주인공 하나.** 한 화면(칸, 설정 쪽, 메뉴)에서 가장 먼저 눈에 들어갈 것을 하나 정하고, 나머지는 거기에 맞춰 한 단계씩 물러선다.
3. **위계는 '덜 쓰는 수단'부터.** 위계를 만들 때 고르는 순서: 여백(묶음) → 명도(글자 단계) → 크기 → 굵기 → 색. 앞의 수단으로 풀리면 뒤의 수단을 쓰지 않는다.
4. **같은 것은 같게, 다른 것은 확실히 다르게.** 두 값이 비슷하면(13과 14, 0.10과 0.12) 하나로 합친다. 다르게 보여야 하면 한 단계 이상 떨어뜨린다.
5. **수학보다 눈.** 격자에 맞춘 뒤, 눈으로 어긋나 보이는 곳만 '눈 보정'(4장)으로 고친다. 보정에는 이름과 까닭을 붙인다.

## 2. 단계표

### 2.1 간격 (4pt 격자)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `SP_HAIR` | 2 | 붙어 있는 것 사이(선택 줄 위아래 틈, 아이콘과 배지) |
| `SP_XS` | 4 | 한 덩어리 안(아이콘과 화살표, 단추 묶음 안) |
| `SP_S` | 8 | 같은 묶음의 이웃(아이콘과 글자, 칸 사이, 바깥 여백) |
| `SP_M` | 12 | 줄 안쪽 여백(탭 글자, 카드 안 글 시작) |
| `SP_L` | 16 | 칸·카드 안쪽 여백, 서로 다른 묶음 사이 |
| `SP_XL` | 24 | 큰 묶음 사이(설정 카드 사이, 미리 보기 카드 바깥) |
| `SP_XXL` | 32 | 화면 구역 사이(시작 화면의 구역) |

규칙
- **묶음 안 여백 < 묶음 사이 여백.** 최소 한 단계 차이(8 안 / 16 사이). 구역 이름은 아래 내용에 더 가깝게: 위 24, 아래 8.
- 4의 배수가 아닌 값은 2(`SP_HAIR`)와 아래 '눈 보정'뿐이다.
- 1px 선(구분선·테두리)은 간격이 아니라 선이다. 선 자리를 위해 간격을 1만큼 줄이지 않는다.

### 2.2 크기

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `ROW_H` | 28 | 모든 줄(파일, 경로, 열 머리, 사이드바, 메뉴) |
| `CTRL_H` | 32 | 단추·입력 칸·레일 타일 |
| `HEAD_H` | 44 | 칸 머리(탭 줄), 레일 너비 |
| `BAR_H` | 52 | 작업 막대 |
| `ICON` | 16 | 기본 아이콘 |
| `ICON_S` | 12 | 화살표·보조 아이콘 |
| `ICON_XS` | 10 | 장식(정렬 표시, 체크 옆 점) |

- 누를 수 있는 것은 최소 28×28(마우스), 맥 트랙패드도 같다. 그림이 작아도 누르는 자리는 이 크기다.

### 2.3 둥글기 (안쪽 = 바깥 − 안쪽 여백, 최소 4)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `R_CARD` | 14 | 칸, 카드, 떠 있는 판(메뉴·미리 보기 카드) |
| `R_CTRL` | 10 | 단추, 입력 칸, 레일 타일 |
| `R_ROW` | 6 | 줄 강조(파일·사이드바·메뉴 줄) |

- 지금 다섯 가지(14·10·8·6·?)를 세 가지로 줄인다. 사이드바 줄의 8은 6으로.
- 메뉴 판 14 안의 줄은 14 − 6(안쪽 여백) = 8이 계산 값이지만, 줄 강조는 모두 `R_ROW` 6으로 맞춘다(같은 것은 같게).

### 2.4 글자

| 이름 | 크기 / 줄 높이 | 굵기 | 자간 | 쓰는 곳 |
|---|---|---|---|---|
| `T_TITLE` | 15 / 20 | 600 | −0.2 | 작업 공간 이름, 설정 쪽 제목, 카드 제목 |
| `T_BODY` | 13 / 18 | 400 | 0 | 파일 이름, 메뉴, 경로, 본문 |
| `T_BODY_STRONG` | 13 / 18 | 600 | 0 | 지금 탭, 고른 값 |
| `T_SMALL` | 12 / 16 | 400 | 0 | 날짜·크기 열, 설명, 캡션 |
| `T_LABEL` | 11 / 14 | 400 | +0.1 | 구역 이름('모든 공간'), 개수 |
| `T_MONO` | 12 / 18 | 400 | 0 | 글 파일 미리 보기 |

규칙
- **굵기는 400과 600 두 가지만.** 700 이상, 300 이하는 쓰지 않는다.
- **위계는 크기보다 명도 먼저.** 같은 13이라도 이름은 `text`, 날짜는 `dim`이면 충분하다. 크기를 바꾸는 것은 제목(15)과 꼬리 정보(12·11)뿐.
- **제목과 본문은 크기 차이(15/13)가 작으니 굵기를 함께 쓴다.** 크기만으로 위계를 만들지 않는다.
- **자간**: 큰 글자는 조이고 작은 글자는 연다(위 표). Windows는 Segoe UI Variable의 광학 크기에, 맥은 SF의 자동 자간에 먼저 맡긴다. 표의 값은 그 위에 더하는 것이므로 렌더 비교 뒤 확정한다.
- **숫자**는 열 안에서 자리를 맞추도록 고정폭 숫자(tabular)를 쓴다(크기·날짜 열). 크기 형식은 한 가지(`306 KB`, `4.5 MB`).
- 대문자 영어 라벨, 기울임, 밑줄 강조는 쓰지 않는다.

### 2.5 색과 명도

색 역할은 `Theme`(21개)을 그대로 쓴다. 글자는 세 단계로만:

| 역할 | 쓰는 곳 | 바탕 대비 |
|---|---|---|
| `text` | 이름, 제목, 고른 값 | 7:1 이상 |
| `dim` | 날짜·크기·경로 앞부분, 설명 | 4.5:1 이상 |
| `faint` | 개수, 꺼진 항목, 자리 표시 글 | 3:1 이상 (작은 글자에는 쓰지 않는다) |

- 강조 색은 화면마다 한 곳: 선택, 켜진 단추, 포커스. 같은 화면에 강조 색 덩어리가 둘 이상 보이면 하나를 무채색으로 돌린다.
- 바탕 단계는 `window` → `pane` → `field`/`control` 순서로만 쌓는다(한 단계씩).

### 2.6 투명도와 그림자

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `A_HOVER` | 0.06 | 마우스를 올린 줄·단추 겹침 |
| `A_PRESS` | 0.10 | 누르는 중, 끌 때 자리 표시 |
| `A_SCRIM` | 0.16 | 떠 있는 판 뒤를 흐리게 |
| `A_DISABLED` | 0.40 | 꺼진 것 전체 |
| `SHADOW_S` | 반경 6, 0.06 | 칸·카드 |
| `SHADOW_M` | 반경 16, 0.12 | 떠 있는 판(메뉴, 끄는 카드) |

- 지금 흩어진 0.08·0.12·0.14 같은 값은 위 넷 가운데 가장 가까운 것으로 합친다.
- 어두운 테마는 그림자 대신 바탕 단계와 1px 선으로 깊이를 낸다.

## 3. 위계 규칙 (화면별)

| 화면 | 주인공 | 둘째 | 물러서는 것 |
|---|---|---|---|
| 칸 | 파일 이름(`T_BODY`, `text`) | 지금 탭, 경로 마지막 폴더 | 날짜·크기(`T_SMALL`, `dim`), 경로 앞부분(`dim`), 개수(`T_LABEL`, `faint`) |
| 도구 막대 | 없음: 모두 같은 단계의 단추 | 켜진 단추(`control` + 강조 아이콘) | 꺼진 단추(아이콘 `dim`) |
| 사이드바 | 지금 위치 줄(선택 바탕) | 고정한 곳 이름 | 구역 이름(`T_LABEL`, `faint`, 위 24·아래 8) |
| 메뉴 | 줄 글(`T_BODY`) | 하위 메뉴 화살표 | 구분선, 꺼진 줄(`faint`) |
| 설정 | 쪽 제목(`T_TITLE`) | 카드 안 항목 이름 | 설명(`T_SMALL`, `dim`) |
| 미리 보기 카드 | 그림·내용 | 파일 이름(`T_BODY_STRONG`) | 종류·크기(`T_SMALL`, `dim`) |

- **의도적 비대칭**은 정보가 한쪽으로 흐를 때만: 왼쪽 정렬 글 + 오른쪽 정렬 숫자(크기 열), 제목 왼쪽 + 동작 단추 오른쪽. 가운데 정렬은 짧은 한두 줄(빈 칸 안내, 썸네일 캡션)에만.
- **면적 대비**: 강조 색은 작은 면적(점, 아이콘, 2px 선, 선택 바탕)에만. 넓은 면적은 무채색.

## 4. 눈 보정

격자에 맞춘 뒤 어긋나 보이는 곳만 고친다. 보정마다 이름 붙은 상수로 둔다.

| 이름 | 값 | 까닭 |
|---|---|---|
| `NUDGE_GLYPH_Y` | +0.5 | 아이콘 글꼴은 글자 기준선보다 위에 앉아 보인다: 같은 줄의 글자와 가운데를 맞춘다 |
| `NUDGE_CHEVRON_X` | +1 | 오른쪽 화살표(›)는 무게가 왼쪽에 있어 상자 가운데에서 왼쪽으로 보인다 |
| `NUDGE_PLAY_X` | +1 | 삼각형 아이콘(재생·펼침)도 같은 까닭 |
| `NUDGE_ROUND_ICON` | 크기 +1 | 둥근 아이콘(눈, 검색)은 같은 크기의 네모 아이콘보다 작아 보인다 |
| `NUDGE_CAPS_TOP` | −1 | 숫자·영어 대문자만 있는 줄은 아래로 처져 보인다 (개수 배지) |

- 보정은 1px 이하가 원칙이다. 그보다 크면 단계가 잘못된 것이다.
- 새 보정은 전·후 그림(200% 확대)을 남기고 추가한다.

## 6. 고치는 순서 (제안)

1. 상수 만들기: 2장의 이름을 공통 코드에 추가한다 (값은 그대로 두고 이름만).
2. 화면 하나씩 옮기기: 사이드바 → 칸 → 도구 막대 → 메뉴 → 설정. 화면마다 전·후 그림으로 확인한다.
3. 단계 밖 값을 합친다 (둥글기·투명도·간격). 화면이 달라지는 부분이라 그림으로 고른다.
4. 글자 줄 높이·자간·고정폭 숫자: 렌더 비교로 값을 확정한 뒤 넣는다.
5. 눈 보정: 200% 확대 그림으로 하나씩.
