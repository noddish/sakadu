# 검색 권한 확인 절차 (일반 계정 두 개)

검색 서비스(SakaduIndex)는 SYSTEM 권한으로 디스크 전체의 이름을 모아 두지만, 검색 결과는 **검색한 Windows 계정이 볼 수 있는 것만** 돌려줍니다.

- 항목이 보이려면 드라이브 루트부터 그 항목을 담은 폴더까지 모두 그 계정이 "폴더 내용 보기"(FILE_LIST_DIRECTORY)를 할 수 있어야 합니다. 탐색기로 열어 볼 수 있는 범위와 같습니다.
- 볼 수 없는 항목은 경로, 순위, 전체 개수("N개 중 M개") 어디에도 들어가지 않습니다.
- 폴더 이름 자체는 그 폴더를 담은 상위 폴더를 볼 수 있으면 보입니다. 탐색기에서도 폴더 이름은 보이고 안은 열리지 않는 것과 같습니다.
- 판정은 로그온 세션별로 기억합니다. 폴더 권한이 바뀌거나 폴더가 옮겨지면 USN 저널로 알아채고 다시 판정합니다.

아래 절차는 Windows 실기에서 사람이 직접 확인하는 방법입니다. 자동 테스트(`cargo test acl:: -- --ignored`)는 한 계정의 실제 권한으로만 확인합니다.

## 준비

1. 이 버전의 검색 서비스로 바꿉니다. 관리자 승인이 필요합니다.
   - Sakadu 설정 → 검색 → 검색 서비스 **제거…** 를 누른 뒤 다시 **설치…**
   - 또는 관리자 터미널에서 `sakadu.exe --install-service`
2. 일반(표준) 계정 두 개를 준비합니다. 여기서는 `사용자A`, `사용자B`라고 부릅니다. 둘 다 Administrators 그룹이 아니어야 합니다.
3. 관리자 터미널에서 시험 폴더를 만듭니다. `사용자A`·`사용자B`는 실제 계정 이름으로 바꿉니다.

```bat
mkdir C:\검색권한시험\공용
mkdir C:\검색권한시험\A만
echo x> C:\검색권한시험\공용\권한시험-공용.txt
echo x> C:\검색권한시험\A만\권한시험-A만.txt
icacls C:\검색권한시험\A만 /inheritance:r /grant:r "사용자A:(OI)(CI)F" "SYSTEM:(OI)(CI)F" "Administrators:(OI)(CI)F"
```

4. `사용자A`로 로그인해 `C:\Users\사용자A\Documents\권한시험-A문서.txt`를 만듭니다. 사용자 프로필은 기본으로 본인과 SYSTEM, 관리자만 열 수 있습니다.

## 확인

| 순서 | 계정 | 검색어 | 기대 결과 |
|---|---|---|---|
| 1 | 사용자A | `권한시험` | 공용, A만, A문서 3개. 아래쪽 "3개 중 3개" |
| 2 | 사용자B | `권한시험` | 공용 1개만. 아래쪽 "1개 중 1개" (숨겨진 2개가 개수에도 없음) |
| 3 | 사용자B | `권한시험-A만` | 결과 없음 |
| 4 | 사용자B | `A만` | 폴더 `C:\검색권한시험\A만` 하나 (폴더 이름은 보이고 안은 안 보임) |
| 5 | 사용자B | `사용자A` | `C:\Users\사용자A` 폴더 이름만. 그 안의 파일·폴더는 나오지 않음 |

빠른 사용자 전환으로 두 계정을 번갈아 써도 됩니다. 각 계정은 자기 세션의 결과만 받습니다.

## 권한이 바뀌면 따라가는지

1. 관리자 터미널: `icacls C:\검색권한시험\A만 /grant "사용자B:(OI)(CI)RX"`
2. 몇 초 뒤 `사용자B`에서 `권한시험-A만`을 다시 검색합니다. 결과에 나와야 합니다.
3. 관리자 터미널: `icacls C:\검색권한시험\A만 /remove "사용자B"`
4. 몇 초 뒤 다시 검색합니다. 다시 나오지 않아야 합니다.

## 정리

```bat
rmdir /s /q C:\검색권한시험
del C:\Users\사용자A\Documents\권한시험-A문서.txt
```

## 참고

- 관리자 계정으로 **관리자 권한으로 실행**한 Sakadu는 관리자 토큰으로 판정합니다. 같은 사람이라도 일반 권한 창과 결과가 다를 수 있습니다. 탐색기의 동작과 같습니다.
- 계정을 확인하지 못한 요청(익명 등)에는 결과를 주지 않습니다.
- 검색에 넣은 폴더(공유폴더·USB)는 서비스가 아니라 앱이 내 계정으로 읽으므로 원래부터 내 계정이 볼 수 있는 것만 나옵니다.
- 예전 버전의 서비스가 그대로 설치돼 있으면 이 판정이 적용되지 않습니다. 준비 1번을 꼭 해 주세요.
