# 사카두 스타일 시트 (지금 값)

사카두 화면의 색·글자·크기·간격 값을 한곳에 모은 것이다. 다른 사람이나 AI에게 사카두 디자인을 설명할 때 이 파일 하나를 주면 된다.

- 기준: 2026-11-25, 가지 `design/sidebar`. 이 가지에서 사이드바와 칸을 단계 이름으로 옮기고 글자(2장)를 고쳤다. main(v0.9.0)과 다른 곳은 6장에 적었다.
- 규칙(왜 이 값인지, 위계, 눈 보정)은 [design-rules.md](design-rules.md)에 있다. 이 파일은 값 목록이다.

## 0. 이 앱은 무엇으로 그리나

- **Rust로 화면을 직접 그린다.** 웹(Electron·Tauri), WPF·WinUI(XAML), Qt(QSS) 같은 UI 틀을 쓰지 않는다. CSS나 XAML 같은 스타일 파일은 없다.
  - Windows: Win32 창 + Direct2D(그리기) + DirectWrite(글자). 입력 상자 몇 개만 Windows EDIT 컨트롤이다.
  - macOS(시제품): AppKit 창 + Core Graphics + Core Text.
- 값은 Rust 상수다. 두 OS가 같이 쓰는 공통 코드에 있다.
  - `src/palette.rs`: 색, 둥글기
  - `src/ui.rs`: 간격·크기 단계, 칸 자리 계산
  - `src/ui/*.rs`: 도구 막대·메뉴·레일·미리 보기 카드
  - `src/gfx.rs`(Windows), `src/mac/gfx.rs`(macOS): 글꼴 표
  - `src/typo.rs`: 글자 단계, 고정 줄 높이 계산, 파일 이름 줄임, 날짜 열, DirectWrite 도우미(한글 대체 글꼴, 고정폭 숫자)
- 단위는 DIP(96dpi의 1px, 맥은 point). 화면 배율은 그리는 쪽이 곱한다.
- 아래 3장의 CSS 꼴 표기는 **설명용**이다. 앱이 읽는 파일이 아니다.

## 1. 색

색은 역할 이름으로 쓴다. 밝게·어둡게 두 벌이 있고, Windows 고대비 모드에서는 시스템 색으로 만든다.

**강조 색에서 계산하는 것**
- 파랑이 아니면: `accent_soft` = `pane`에 강조 색 12%(어둡게 22%), `sel` = `pane`에 강조 색 20%(어둡게 35%)
- 회색 한 벌에 강조 색을 아주 옅게 섞는다: `window`, `strip`, `field`, `hover`, `sel_inactive`, `border`, `pane_border`, `thumb`에 4%(어둡게 6%). 어느 작업 공간인지 바탕색으로도 알아본다.
- 마우스 올림 겹침: 밝게는 `text`를 6% 투명도로, 어둡게는 흰색 6%

## 2. 글자

**글꼴**

- Windows 글꼴: **Segoe UI Variable Text** (없으면 Segoe UI). 설정에서 다른 글꼴을 고를 수 있다.
- **한글은 Segoe에 없다.** Segoe UI Variable은 라틴·그리스·키릴 문자만 있다. 그래서 한글은 늘 대체 글꼴로 그린다.
  - 대체 글꼴은 시스템에 맡기지 않고 앱이 정한다(`IDWriteFontFallbackBuilder`). 기본은 맑은 고딕(Malgun Gothic). 그 밖의 글자는 시스템 대체 규칙을 그대로 잇는다.
  - 한글 범위: `1100–11FF`(자모, 맥에서 온 NFD 이름), `3130–318F`, `A960–A97F`, `AC00–D7A3`(완성형), `D7B0–D7FF`
  - 크기 보정: 0.97 (0.96·0.97·0.98을 화면으로 비교해 정함, `src/gfx.rs` `HANGUL_SCALE`)
    - 회색조·선명하게(기본)는 글자를 픽셀 크기로 반올림해 그린다. 13px × 0.97 = 12.6 → 13px이라 화면은 보정 전과 같다. 0.96부터 한글이 12px로 한 단계 작아진다.
    - 부드럽게에서만 0.97만큼 미세하게 줄어든다.
    - 맑은 고딕이 없거나 Windows 8.1보다 오래되면 시스템 대체 규칙 그대로다.
  - 맑은 고딕은 굵기가 350·400·700뿐이다. 600을 요청하면 한글은 700으로 그려진다(`Title`, `Strong`, `Label`). 영문은 600, 한글은 700으로 섞이는 것을 알고 쓴다.
- 아이콘 글꼴: Segoe Fluent Icons (없으면 Segoe MDL2 Assets). 책갈피만 도형으로 그린다.
- 고정폭: Cascadia Mono (없으면 Consolas). 한글은 위와 같은 대체 글꼴로 그린다.
- macOS: 시스템 글꼴(SF), 아이콘은 SF Symbols. 한글은 Apple SD Gothic Neo로 대체되며, 이 글꼴은 SemiBold가 있어 600이 그대로 600이다.
- 글자 그리기 방식(설정): 부드럽게(DirectWrite 기본) / 선명하게(GDI ClearType식) / 회색조(선명하게 + 색 번짐 없음)

**단계**

| 이름 | 크기 | 굵기 | 숫자 | 줄 높이 / 기준선 | 정렬·줄바꿈 | 쓰는 곳 |
|---|---|---|---|---|---|---|
| `Title` | 15 | 600 | 비례폭 | 20 / 16 | 왼쪽, 한 줄 | 작업 공간 이름, 설정 쪽 제목 |
| `Normal` | 13 | 400 | 비례폭 | 18 / 14 | 왼쪽, 한 줄, 끝 말줄임 | 탭, 메뉴, 본문 |
| `Name` | 13 | 400 | 비례폭 | 18 / 14 | 왼쪽, 한 줄, 가운데 말줄임(꼬리 남김) | 파일 이름 (자세히·목록 보기) |
| `Strong` | 13 | 600 | 비례폭 | 18 / 14 | 왼쪽 | 강조 본문, 사이드바 그룹 머리('월간', '서비스지원') |
| `Meta` | 13 | 400 | 고정폭 | 18 / 14 | 왼쪽, 한 줄 | 날짜 열 (색 `dim`) |
| `MetaRight` | 13 | 400 | 고정폭 | 18 / 14 | 오른쪽 | 크기 열 (색 `dim`) |
| `Path` | 13 | 400 | 비례폭 | 18 / 14 | 넘치면 가운데를 줄이고 마지막 폴더 이름을 남김 | 경로 입력 |
| `Hint` | 13 | 400 | 비례폭 | 20 / 15 | 가운데, 줄바꿈 | 빈 칸 안내 |

| `Label` | 12 | 600 | 비례폭 | 16 / 13 | 왼쪽 | 구역 이름('모든 공간', 설정 카드 머리, 시작 화면 구역), 색 `faint` |
| `Glyph` / `GlyphMid` / `GlyphSmall` | 16 / 12 / 10 | | | | 가운데 | 아이콘 |

- 굵기는 400과 600 두 가지만 쓴다. 올림·선택 때 굵기를 바꾸지 않는다(글자 폭이 바뀌어 줄이 흔들린다). 상태는 5장대로 바탕색으로만 보인다.
- 가장 작은 글자는 12다. 아이콘(`GlyphSmall`)만 예외.
- 자간: 글꼴 기본값이다(따로 조정하지 않음).

**줄 높이와 기준선**

- 글꼴 기본값 대신 고정한다(DirectWrite `DWRITE_LINE_SPACING_METHOD_UNIFORM`, macOS는 기준선을 직접 정해 그림).
- 주 글꼴(Segoe) 지표로만 계산하고 대체 글꼴 지표는 섞지 않는다. 그래서 한글 이름 줄과 영문 이름 줄의 기준선이 같다.
  - 줄 높이 = ⌈(ascent + descent) × 크기⌉, 기준선 = round(ascent × 크기)
  - 앱은 실행할 때 그 글꼴·굵기의 지표를 읽어 계산한다(값을 코드에 적어 두지 않음). Segoe UI Variable Text에서 읽은 값은 ascent 1.079, descent 0.251 em이고, 표의 줄 높이·기준선은 이 값으로 나온 것이다. Cascadia Mono는 0.928 / 0.234.
  - 여러 줄로 쓰는 `Hint`(20)와 `Mono`(18)는 줄 높이를 넉넉히 두고, 늘어난 만큼 위아래로 나눠 기준선을 내린다.
  - 아이콘 글꼴은 고정하지 않는다(글자 하나를 가운데 그린다).
- 글자 상자는 줄 안에서 세로 가운데에 둔다. 예: `ROW_H` 28 안에 18 상자 → 위 5.
- 확인: 한글·영문이 섞인 목록(15줄)을 100·125·150%로 재 보니 줄마다 기준선이 같았다. 고정 전과 비교하면 100·125%는 픽셀까지 같고, 150%에서 모든 줄이 똑같이 1px 올라갔다.

**숫자**

- 날짜·크기·개수는 고정폭 숫자(OpenType `tnum`)를 켠다(`Meta`, `MetaRight`, `Small`). 기본값에 기대지 않는다. Segoe UI는 굵기에 따라 기본 숫자 폭이 다르고, 맥 시스템 글꼴은 비례폭이 기본이다.
  - Windows: 글자 형식에는 붙일 수 없어 그 단계의 글자를 배치할 때마다 붙인다. 너비 재기도 같은 배치를 쓴다.
  - macOS: `monospacedDigitSystemFontOfSize:weight:` 글꼴을 쓴다.
- 이름·경로 안의 숫자는 비례폭 그대로다.

**파일 이름 줄임** (`Name`)

- 자세히·작은 아이콘·목록 보기의 파일 이름. 넘치면 가운데를 줄이고 꼬리를 끝까지 남긴다. 예: `20261124 - 프리미어…집계표.xlsx`
- 꼬리: 확장자가 있으면 확장자 + 그 앞 3 글자 덩어리, 없으면 끝 5 글자 덩어리.
- 확장자로 보는 것: 맨 앞 점이 아님(`.gitignore`는 아님), 점 뒤가 1~8 글자 덩어리, 빈칸 없음.
- 좁아지면 앞부분부터 줄인다. 앞부분이 2 글자 덩어리도 안 남으면 끝 말줄임으로 물러선다. 말줄임표 앞 빈칸은 지운다(뒤 빈칸은 남는다: `2026… 보고.xlsx`).
- 자르는 단위는 글자 덩어리(grapheme)다(`unicode-segmentation`). `Caption`의 두 줄 끊기는 글꼴이 글자 덩어리 단위로 한다.
- **맥에서 온 NFD 한글 이름은 그릴 때 완성된 글자로 합친다**(`typo::display_name` → `hangul::compose`). Windows 글꼴은 나뉜 자모를 한 글자로 합쳐 그리지 않아 'ㄱㅏ'처럼 풀려 보이기 때문이다. 파일 이름 자체(열기·이름 바꾸기·복사에 쓰는 이름)는 바꾸지 않는다. 그림 아래 이름(`Caption`)도 합쳐 그린다.
- 줄였으면 올렸을 때 말풍선으로 전체 이름(합친 글자)을 보여 준다(Windows).
- 줄임 결과는 (보일 이름, 폭)으로 기억해 둔다(4,096개가 차면 비움). 글꼴·배율·글자 그리기 방식이 바뀌면 비운다. 맥은 기억하지 않고 매번 계산한다.
- GDI식 그리기는 글자 상자 양 끝을 픽셀에 맞추며 1px까지 좁아질 수 있어, 이름은 1 덜 넓다고 보고 맞춘다(`NAME_FIT_SLACK`).

**날짜 열**

- 날짜 꼴은 두 가지다(설정): 짧게(기본: `방금`, `오늘 09:21`, `어제 14:03`, `11월 2일`, 다른 해는 `2025-11-02`)와 길게(`2026-11-02 14:03`).
- **기본 폭은 내용으로 잰다**(`ui::date_col_width`). 고정폭 숫자라 0으로 채운 꼴만 재면 된다.
  - 긴 꼴: `0000-00-00 00:00` + 양쪽 여백 16
  - 짧은 꼴: `방금 / 오늘 00:00 / 어제 00:00 / 00월 00일 / 0000-00-00` 가운데 가장 넓은 것 + 여백
  - 머리글('수정한 날짜'와 정렬 화살표 자리)보다 좁게 하지는 않는다(탐색기의 자동 맞춤과 같다).
  - 배율·날짜 꼴·글자 그리기 방식·글꼴이 같으면 다시 재지 않는다. 남는 폭은 전부 이름 열에 준다.
- **사용자가 끌어 정한 폭은 그대로 둔다.** 저장된 폭이 예전 기본값 140이면 '자동'으로 보고 내용 폭을 쓴다(`pane::DATE_AUTO`). '자동' 열을 끌면 보이는 폭에서 시작해 그 폭으로 정해진다.
- 긴 꼴은 열이 좁으면 말줄임하지 않고 짧은 꼴로 바꾼다: `2026-11-03 15:18` → `26-11-03 15:18` → `오늘 15:18` 또는 `26-11-03` → `11-03`. 짧은 꼴은 그대로 둔다.
- 맥은 열 끌기가 없고 폭 140 그대로다(긴 꼴이 140 안에 들어간다).

**큰 글자** (계획, 아직 없음)

- 설정에서 켜면 모든 단계가 1씩 커진다(`Normal` 14, `Title` 16, `Small`·`Caption`·`Label` 13). 줄 높이·기준선은 같은 식으로 다시 계산하고, 파일 줄 높이는 28 → 32.

## 3. 간격·크기·둥글기·투명도

```css
/* 설명용 표기 (앱이 읽는 파일 아님). 이름은 Rust 상수 이름 */
:root {
  /* 간격: 4pt 격자 */
  --SP_HAIR: 2px;  --SP_XS: 4px;  --SP_S: 8px;  --SP_M: 12px;
  --SP_L: 16px;    --SP_XL: 24px;
  --MARGIN: 8px;   /* 창 바깥 여백 */
  --GAP: 8px;      /* 칸 사이 */

  /* 크기 */
  --ROW_H: 28px;          /* 파일 줄, 경로 줄, 열 머리, 사이드바 줄, 메뉴 줄 */
  --HEAD_H: 44px;         /* 칸 머리 (탭 줄) */
  --WORKBAR_H: 52px;      /* 창 위 작업 막대 */
  --BAR_W: 44px;          /* 왼쪽 레일 폭 */
  --SIDE_HEADER_H: 32px;  /* 사이드바 머리 */
  --TOOL_H: 32px; --TOOL_W: 36px;  /* 도구 막대 단추 */
  --RAIL_ITEM: 32px; --RAIL_PITCH: 40px;
  --ICON: 16px;
  --SCROLL_W: 10px;
  --INDENT: 20px;         /* 그룹 안 들여쓰기 */

  /* 칩·탭·정렬 단추는 알약 (높이의 절반) */
```

**그림자** (흐림 효과 대신 옅은 둥근 사각형 8겹을 아래로 조금씩 키워 겹친다. 밝게는 남색빛 #0F1729, 어둡게는 검정 2.5배)

## 4. 칸 안 자리 (세로선)

칸 왼쪽에서 잰 x. 세 보기(자세히·작은 아이콘·목록)가 같은 선을 쓴다.

| x | 무엇 |
|---|---|
| 8 | 줄 바탕·칩·구분선·경로 조각 바탕이 시작하는 선 |
| 16 | 파일 아이콘, 열 머리 '이름', 경로 첫 글자 |
| 40 | 파일 이름 (아이콘 16 + 간격 8) |
| 오른쪽 16 | 줄 바탕·구분선·열이 끝나는 선 (스크롤 막대 10 + 틈 6) |

- 칸 머리(44): 칩 줄은 위아래 8, 칩 높이 28
- 경로 줄(28): 오른쪽 끝에 책갈피(24×24, 오른쪽 12 안쪽), 그 앞에 보기 단추(44)
- 목록 아래: 둥근 모서리에 닿지 않게 8 띄움

**사이드바 줄** (줄 바탕 왼쪽에서): 아이콘 8, 이름 32 (= 8 + 16 + 8). 작업 공간 이름도 아이콘과 같은 선이다.

## 5. 상태 표시

| 상태 | 모양 |
|---|---|
| 올림 | 줄·단추에 `hover` 또는 A_HOVER 겹침 |
| 선택 | `sel` 바탕 (다른 칸이면 `sel_inactive`) |
| 키보드 포커스 | `focus` 색 1.25px 테두리, 둥글기 그대로 |
| 끌어 놓을 자리 | `accent` 1.5px 테두리 + `accent` 10% 바탕 |
| 지금 탭 | 알약 칩, 활성 칸이면 `accent_soft` 바탕에 `chip_text` 글자 |
| 켜진 도구 단추 | 단추판 안쪽 3에 `accent_soft` 판, 아이콘은 `chip_text` |
| 열린 고르기 단추 | `accent_soft` 판, 글자·아이콘 `chip_text` |
| 꺼짐 | `faint` 글자, 또는 A_DISABLED |

## 6. main(v0.9.0)과 다른 곳

이 가지에서 바꾼 값이다. 아직 main에 합치지 않았다.

- 사이드바 줄 둥글기 8 → 6 (`R_ROW`로 합침). 줄 안 아이콘 10 → 8, 이름 36 → 32. 떠 있는 사이드바 카드 둥글기 12 → 14.
- 경로 첫 글자 20 → 16 (아이콘 선에 맞춤). 작은 아이콘·목록 보기의 아이콘 12 → 16.
- 큰 아이콘 타일·작은 아이콘 칸의 오른쪽 끝을 줄 바탕과 같은 선(오른쪽 16)으로.
- 지금 칸 그림자 12/0.10 → 16/0.12. 흩어진 투명도(0.045·0.075·0.08·0.12·0.14·0.15·0.45)를 0.06·0.10·0.40으로 합침.
- 글자(2장):
  - `Label` 11/400 → 12/600 (색 `faint` 그대로). 세 가지 그리기 방식에서 한글 획이 뭉개지지 않았다. 다만 옅은 색 12px라 굵기 차이는 '조금 진해진' 정도로 보인다.
  - 사이드바 그룹 머리 `Normal` → `Strong` (Windows·맥, 그룹을 끌 때의 카드도)
  - 새 단계 `Name`(파일 이름, 가운데 말줄임), `Meta`(날짜 열, 고정폭 숫자), `MetaRight`(크기 열. 예전 `Right` 자리, 고정폭 숫자). `Right`는 열 머리글의 오른쪽 정렬에만 남았다.
  - `Small`: 고정폭 숫자를 켬
  - 줄 높이·기준선: 글꼴 기본값 → 주 글꼴 지표로 고정 (Windows UNIFORM, 맥은 기준선을 직접 정함)
  - 한글 대체 글꼴: 시스템에 맡김 → 앱이 지정 (맑은 고딕, 보정 0.97)
  - 파일 이름: 끝 말줄임 → 가운데 말줄임(확장자 남김), 줄이면 말풍선. NFD 한글은 그릴 때 합침
  - 날짜 열: 기본 폭 140 → 내용 폭(머리글 포함). 좁으면 긴 꼴을 짧은 꼴로
- 의존성 추가: `unicode-segmentation` 1.13 (파일 이름을 글자 덩어리 단위로 자름)
- 시험용 환경 변수 `SAKADU_HANGUL_SCALE`(0.9~1.0, `system`이면 시스템 대체): 한글 보정값을 다시 빌드하지 않고 비교할 때 쓴다.
- 확인하지 못한 것: 맥 화면(CI `mac-screens` 그림으로 볼 수 있다), 줄인 이름 위 말풍선(시험 창에서 마우스를 올릴 수 없음), 열을 마우스로 끌어 좁히기(세션에 폭을 적어 확인함).
- 아직 옛 값인 곳: 도구 막대, 메뉴(구분선 9, 체크·아이콘 칸 26 등), 설정, 시작 화면, 미리 보기.
