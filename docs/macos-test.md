# 사카두 맥 시제품 확인 부탁 (1차)

사카두는 Windows용으로 만든 한국어 파일 관리자예요. 맥에서도 쓸 수 있게 만드는 중인데, 개발자에게 맥이 없어서 실제 맥에서 손으로 써 봐야 아는 것을 부탁드려요. 30분쯤 걸려요.

이번 시제품은 **폴더를 보고 옮겨 다니는 것까지만** 돼요. 파일을 복사하거나 지우는 기능은 아직 없으니, 중요한 파일이 바뀔 걱정은 없어요.

> **보내는 사람용**: PR의 CI 결과(Checks → CI → `mac-app`)에서 아티팩트 `Sakadu-mac`을 받아 압축을 풀면 `Sakadu-…-mac-prototype.zip`이 나와요. 이 zip을 그대로 전달하면 돼요.

## 1. 받기와 처음 열기

1. `Sakadu-…-mac-prototype.zip`을 더블클릭해서 풀면 `Sakadu.app`이 나와요. 응용 프로그램 폴더로 옮기지 않아도 돼요.
2. `Sakadu.app`을 더블클릭하면 "열 수 없습니다" 같은 안내가 뜨고 막혀요. Apple 개발자 등록과 공증을 아직 하지 않은 시제품이라 그래요.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽 보안 항목의 'Sakadu'(이)가 차단되었다는 줄 옆 **그래도 열기**를 눌러요. 다시 열면 한 번 더 묻는데, **열기**를 누르면 돼요.
4. macOS 13(Ventura) 이상이면 Apple Silicon 맥과 Intel 맥 모두 돌아가요.

## 2. 가능하면 시험용 계정에서

- 시스템 설정 → 사용자 및 그룹에서 새 사용자를 하나 만들어, 그 계정에서 시험해 주세요.
- **'전체 디스크 접근' 권한은 주지 마세요.** 이번 확인에는 필요 없어요.
- 문서·다운로드·데스크탑 폴더를 처음 열 때 "접근하려고 합니다"라는 창이 뜨면, 시험용 계정에서는 허용해도 돼요. 이 창이 어떻게 뜨는지도 확인할 거리예요.

## 3. 확인할 것

느낀 대로 적어 주시면 돼요. 특히 **어색한 곳**이 궁금해요.

1. **첫인상**: 맥 앱처럼 보이나요? 글꼴, 간격, 색, 아이콘, 왼쪽 위 닫기·최소화·확대 단추의 자리가 어색하지 않은가요?
2. **트랙패드 스크롤** (중요)
   - 두 손가락으로 목록을 올리고 내릴 때 자연스러운가요?
   - 손을 떼도 조금 미끄러지는 관성이 있나요?
   - 끝에서 멈추는 느낌은 어떤가요?
   - 왼쪽 사이드바도 줄이 많으면 스크롤돼요.
3. **한글 입력** (가장 중요)
   - 경로 줄(위쪽 `… > 폴더 > 폴더` 줄)의 빈 곳을 누르거나 **⌘L**을 누르면 경로를 입력할 수 있어요.
   - 한글 이름이 들어간 경로를 쳐 보세요. 예: `~/문서/회의록`처럼 한글 폴더를 하나 만들어 두고 입력해요.
   - 조합 중인 글자가 바로 보이나요? 글자가 빠지거나 두 번 들어가지는 않나요?
   - Return을 눌렀을 때 조합만 끝나는지, 그 폴더로 바로 가는지 알려 주세요.
   - Esc로 취소돼요. 없는 경로를 넣으면 위쪽 오른쪽에 알림이 떠요.
   - **⌘⇧G**(Finder의 '폴더로 이동')로도 열려요.
4. **마우스**
   - 누르면 고르고, ⌘-누르기로 하나씩 더하고, ⇧-누르기로 범위를 골라요.
   - 폴더를 두 번 누르면 들어가고, 파일을 두 번 누르면 기본 앱으로 열려요.
5. **이동**
   - **⌘↑** 위 폴더, **⌘[** **⌘]** 뒤로·앞으로. 창 위쪽 왼쪽의 화살표 단추로도 돼요(지금 칸에 대해 움직여요).
   - 경로 조각을 누르면 그 폴더로 가요.
   - 위로·뒤로 갔을 때 방금 있던 폴더가 골라져 있나요?
6. **탭**
   - **⌘T** 새 탭, **⌘W** 탭 닫기, **⌃Tab** 다음 탭
   - 탭을 여러 개 열어 넘치게 해 보세요.
7. **칸 나누기**
   - 창 위쪽 오른쪽의 칸 나누기 단추를 누르면 메뉴가 열려요. 다섯 가지 중에 골라요. **⌘⌥1~5**로도 돼요.
   - 메뉴가 단추 바로 아래에 열리나요? 지금 것에 체크 표시가 있나요?
   - **Tab**으로 칸을 옮기고, 칸 사이 경계를 끌어 크기를 바꿔요.
   - 지금 칸은 흰 카드로 떠 있고 다른 칸은 조금 가라앉아 보여요. 어느 칸에 있는지 바로 보이나요?
8. **보기 방식**
   - 칸 나누기 단추 옆의 보기 방식 단추를 누르면 여섯 가지(아주 큰·큰·보통·작은 아이콘, 목록, 자세히)가 나와요.
   - 아이콘 보기에서 화살표 키로 옆·위아래 칸으로 움직여 보세요.
   - 썸네일은 아직 없어서 그림 파일도 파일 아이콘으로 보여요.
9. **작업 공간** (이번에 새로 생긴 곳이에요)
   - 맨 왼쪽에 세로로 놓인 네모 아이콘이 작업 공간이에요. 처음에는 '기본' 하나가 있어요.
   - 그 아래 **+** 를 누르면 지금 화면 그대로 새 공간이 생겨요. 이름을 바로 고칠 수 있어요(Return으로 확정, Esc로 취소).
   - 공간마다 칸 나누기와 탭을 다르게 해 두고, 아이콘을 눌러 오가 보세요. 떠날 때의 화면이 그대로 돌아오나요?
   - 공간마다 색이 달라요. 지금 공간의 색이 탭과 고른 줄에 쓰이고, 창 바탕에도 옅게 묻어요. 어느 공간에 있는지 색으로 알아볼 만한가요? 눈이 피곤하지는 않나요?
   - 아이콘을 **오른쪽 단추**(또는 ⌃-누르기)로 누르면 메뉴가 열려요. 색 바꾸기, 이름 바꾸기, 지우기가 있어요.
     - 메뉴가 아이콘 바로 아래에 열리나요? 지금 색에 체크 표시가 있나요?
     - 마지막 하나 남은 공간에는 지우기가 없어요.
   - **+** 를 오른쪽 단추로 누르면 모든 작업 공간의 목록이 나와요. 창이 낮아 아이콘이 다 보이지 않을 때 여기서 골라요.
   - 아이콘 옆 맨 위 글자가 지금 공간의 이름이에요. 두 번 눌러도 이름을 고칠 수 있어요. 한글 이름이 잘 들어가나요?
10. **사이드바**
    - 공간 이름 아래는 **이 공간에 고정한 곳**이에요. 경로 줄 오른쪽 책갈피나 **⌃⌘T**로 고정하고, 다시 누르면 풀려요.
    - 고정한 곳은 그 공간에서만 보여요. 다른 공간으로 가면 사라지고, 돌아오면 그대로 있나요?
    - 맨 아래 **모든 공간**은 어느 공간에서나 같아요(홈·데스크탑·문서·다운로드·응용 프로그램·디스크).
    - 고정한 곳이 적을 때 '모든 공간'이 사이드바 맨 아래에 붙어 있나요?
    - 지금 보고 있는 폴더의 줄은 흰 카드처럼 떠 보여요.
11. **숨김 파일**: **⌘⇧.** 또는 보기 방식 메뉴 맨 아래의 '숨김 항목 보기'
12. **밝은·어두운 모양**
    - 시스템 설정 → 모양에서 바꾸면 바로 따라 바뀌나요?
    - 강조 색도 바꿔 보세요. 색을 따로 고르지 않은 공간('기본')이 그 색을 따라요.
13. **끝내고 다시 열기**: **⌘Q**로 끝낸 뒤 다시 열면 작업 공간과 칸, 탭, 보기 방식이 그대로인가요?
14. **창**: 창 크기 바꾸기, 초록 단추로 전체 화면, ⌘M 최소화
    - 왼쪽 위 신호등 단추와 그 오른쪽 도구 막대 단추의 높이가 어긋나 보이나요?
    - 도구 막대의 빈 곳을 끌면 창이 움직이나요? 두 번 누르면 창이 커지나요?
    - 창 모서리가 Finder 창만큼 둥근가요?

## 4. 아직 없는 것 (안 되는 게 정상이에요)

- 파일 복사·이동·삭제·이름 바꾸기, 새 폴더, 끌어서 놓기
- 미리 보기·훑어보기(스페이스), 썸네일
- 검색
- 설정, 오른쪽 클릭 메뉴 (작업 공간 아이콘의 메뉴만 있어요)
- '모든 공간'에 넣고 빼기, 고정한 줄의 순서 바꾸기
- 폴더 내용이 바뀌어도 저절로 다시 읽지 않아요 (**⌘R**로 새로 고침)

## 5. 결과 보내기

- 이상한 곳은 화면 녹화(**⌘⇧5** → 선택 부분 기록)나 스크린샷으로 보내 주세요.
- 한 줄씩 메모: **어디서 · 무엇을 했더니 · 어떻게 됐는지**
- 맥 정보: Apple 메뉴 → 이 Mac에 관하여의 macOS 버전, 그리고 칩(Apple M… 또는 Intel)
- **멈추거나 꺼지면 로그를 부탁해요.**
  1. 터미널을 열고 `Sakadu.app`이 있는 곳에서 다음처럼 실행해요.
     ```
     ./Sakadu.app/Contents/MacOS/sakadu-mac --log
     ```
  2. 같은 일을 다시 해 본 뒤 앱을 끝내요.
  3. `open $TMPDIR`로 열리는 폴더의 `sakadu.log`를 보내 주세요.

고맙습니다!
