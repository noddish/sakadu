# 사카두 맥 미리 보기 확인 부탁 (2차)

사카두는 Windows용으로 만든 한국어 파일 관리자예요. 맥에서도 쓸 수 있게 만드는 중인데, 개발자에게 맥이 없어서 실제 맥에서 손으로 써 봐야 아는 것을 부탁드려요. 1차 확인 고맙습니다!

2차에서는 맥 버전도 Windows 버전이 하는 일을 거의 다 하게 됐어요. 그래서 이번부터 Windows 버전과 함께 **판 번호가 붙은 릴리즈**에도 들어가요. 새로 생긴 것은 **25번부터**예요: 새 탭 시작 화면, ⌘K 명령 메뉴, 정렬과 열 폭, 단축키 바꾸기, 사이드바 끌어 옮기기, 문서 미리 보기와 미리 보기 창, 압축 파일 열기, USB 디스크와 NAS, 메뉴 막대 대기, 어디서든 찾기, 로그인할 때 열기, Finder에서 사카두로 열기. 1~24번은 1차와 같은 곳인데, 바뀐 곳에 **(바뀜)**, 더한 줄에 **(새로)**를 붙였어요. 다 하면 1시간 넘게 걸려요. 나눠서 해도 되고, 시간이 모자라면 25번부터 봐 주세요.

실제 파일이 바뀌는 기능(새 폴더, 이름 바꾸기, 휴지통, 붙여넣기, 옮기기, 끌어서 놓기, 되돌리기)은 이번에도 **시험용 폴더 안에서만** 해 봐 주세요(아래 2번). 이번에는 USB 디스크와 NAS로 옮기는 것도 있어서, 쓸 디스크와 공유 폴더에 대한 규칙을 더했어요. 사카두는 있는 파일을 덮어쓰지 않고, 지울 때도 휴지통으로만 보내요. 다른 디스크로 옮길 때도 복사본을 원본과 맞춰 본 뒤에 원본을 휴지통으로 보내요.

> **받는 곳**: [가장 새 릴리즈](https://github.com/noddish/sakadu/releases/latest)에서 `Sakadu-v…-macos.zip`을 받아요(`v…` 자리에 판 번호가 들어가요). 지난 판은 [Releases](https://github.com/noddish/sakadu/releases)에 있어요. 결과를 보내실 때 그 판 번호를 함께 적어 주세요.
>
> 가장 새 릴리즈에 맥 파일이 아직 없거나, 판이 나오기 전의 가장 새 것을 보고 싶을 때는 [맥 미리 보기 릴리즈](https://github.com/noddish/sakadu/releases/tag/mac-preview)에서 `Sakadu-mac.zip`을 받아요 (바로 받기: <https://github.com/noddish/sakadu/releases/download/mac-preview/Sakadu-mac.zip>). main에 합칠 때마다 모든 시험을 통과한 새 것으로 저절로 바뀌어서, 링크는 늘 같아요. 어느 때 만든 것인지는 릴리즈 글에 적혀 있어요.
>
> 아직 합치지 않은 PR을 확인할 때만: 그 PR의 CI 결과(Checks → CI → `mac-app`)에서 아티팩트 `Sakadu-mac`을 받아 압축을 풀면 `Sakadu-…-mac-prototype.zip`이 나와요.

## 1. 받기와 처음 열기

1. 받은 zip을 더블클릭해서 풀면 `Sakadu.app`이 나와요. **(바뀜)** 이번에는 **응용 프로그램 폴더로 옮긴 뒤** 열어 주세요. 로그인할 때 열기(37번)와 Finder의 '다음으로 열기'(38번)는 앱이 늘 같은 자리에 있어야 제대로 볼 수 있어요. 1차 때 받은 앱이 있으면 사카두를 끝내고(⌘Q) 새 것으로 바꿔요.
2. `Sakadu.app`을 더블클릭하면 "열 수 없습니다" 같은 안내가 뜨고 막혀요. Apple 개발자 등록과 공증을 아직 하지 않은 미리 보기라 그래요.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽 보안 항목의 'Sakadu'(이)가 차단되었다는 줄 옆 **그래도 열기**를 눌러요. 다시 열면 한 번 더 묻는데, **열기**를 누르면 돼요. 새로 받을 때마다 한 번씩이에요.
4. macOS 13(Ventura) 이상이면 Apple Silicon 맥과 Intel 맥 모두 돌아가요.
5. **(새로)** 1차 때 쓰던 설정(작업 공간, 고정한 곳 등)은 그대로 남아요. 새 탭 설정도 예전 값('지금 폴더')으로 남으니 25번에서 바꿔 주세요.

## 2. 시험용 폴더에서, 가능하면 시험용 계정에서

- **시험용 폴더를 하나 만들어 주세요.** 예: 데스크탑에 `사카두 시험` 폴더를 만들고, 잃어도 되는 파일을 몇 개 넣어요(글 파일, 사진 복사본, 하위 폴더 한두 개). **새 폴더, 이름 바꾸기, 휴지통, 붙여넣기, 되돌리기는 이 폴더 안에서만** 해 주세요.
- 시스템 설정 → 사용자 및 그룹에서 새 사용자를 하나 만들어, 그 계정에서 시험해 주세요.
- **'전체 디스크 접근' 권한은 주지 마세요.** 이번 확인에도 필요 없어요.
- 문서·다운로드·데스크탑 폴더를 처음 열 때 "접근하려고 합니다"라는 창이 뜨면, 시험용 계정에서는 허용해도 돼요. 이 창이 어떻게 뜨는지도 확인할 거리예요.
- **(새로) USB 디스크**: 비어 있거나 잃어도 되는 것만 든 USB 메모리나 외장 디스크로 해 주세요. 그 안에도 시험용 폴더를 만들어 써요. **저장하지 않은 작업이 있는 디스크는 꺼내지 마세요.** 꺼내기 전에는 그 디스크의 파일을 연 앱에서 저장을 먼저 마쳐요. 꺼내지 않은 디스크를 그냥 뽑지도 마세요.
- **(새로) NAS**: **본인 NAS나 마음대로 써도 되는 공유 폴더**로 해 주세요. 그 안에 시험용 폴더를 만들어 그 안에서만 해요. 회사나 다른 사람과 함께 쓰는 공유에서는 하지 마세요. 암호는 macOS의 로그인 창에만 넣어요(사카두는 암호를 묻지도 저장하지도 않아요).
- **(새로) 다 끝나면**: 설정 → 일반의 '로그인할 때 열기'와 '메뉴 막대에서 대기'를 끄고, 검색에 더한 폴더(34번)를 빼 주세요.

## 3. 확인할 것

느낀 대로 적어 주시면 돼요. 특히 **어색한 곳**이 궁금해요.

1. **첫인상**: 맥 앱처럼 보이나요? 글꼴, 간격, 색, 아이콘, 왼쪽 위 닫기·최소화·확대 단추의 자리가 어색하지 않은가요?
2. **트랙패드 스크롤** (중요)
   - 두 손가락으로 목록을 올리고 내릴 때 자연스러운가요?
   - 손을 떼도 조금 미끄러지는 관성이 있나요?
   - 끝에서 멈추는 느낌은 어떤가요?
   - 왼쪽 사이드바도 줄이 많으면 스크롤돼요.
   - **(새로)** 새 탭 시작 화면(25번), ⌘K 명령 메뉴(26번), 미리 보기 창의 글과 문서(30번), 설정 창도 스크롤해 보세요. 같은 느낌인가요?
3. **한글 입력** (가장 중요)
   - 경로 줄(위쪽 `… > 폴더 > 폴더` 줄)의 빈 곳을 누르거나 **⌘L**을 누르면 경로를 입력할 수 있어요.
   - 한글 이름이 들어간 경로를 쳐 보세요. 예: `~/문서/회의록`처럼 한글 폴더를 하나 만들어 두고 입력해요.
   - 조합 중인 글자가 바로 보이나요? 글자가 빠지거나 두 번 들어가지는 않나요?
   - Return을 눌렀을 때 조합만 끝나는지, 그 폴더로 바로 가는지 알려 주세요.
   - Esc로 취소돼요. 없는 경로를 넣으면 위쪽 오른쪽에 알림이 떠요.
   - **⌘⇧G**(Finder의 '폴더로 이동')로도 열려요.
4. **마우스**
   - 누르면 고르고, ⌘-누르기로 하나씩 더하고, ⇧-누르기로 범위를 골라요.
   - 폴더를 두 번 누르면 들어가고, 파일을 두 번 누르면 기본 앱으로 열려요. **(새로)** 압축 파일(zip 등)은 폴더처럼 들어가요(31번).
5. **이동**
   - **⌘↑** 위 폴더, **⌘[** **⌘]** 뒤로·앞으로. 창 위쪽 왼쪽의 화살표 단추로도 돼요(지금 칸에 대해 움직여요).
   - 경로 조각을 누르면 그 폴더로 가요.
   - 위로·뒤로 갔을 때 방금 있던 폴더가 골라져 있나요?
6. **탭**
   - **⌘T** 새 탭, **⌘W** 탭 닫기, **⌃Tab** 다음 탭
   - **(바뀜)** ⌘T는 이제 새 탭 시작 화면을 열 수 있어요(25번). 1차 때 쓰던 설정이 남아 있으면 지금처럼 지금 폴더가 열려요.
   - **(새로)** **⇧⌘T**: 방금 닫은 탭이 다시 열리나요? 보던 폴더가 맞나요?
   - 탭을 여러 개 열어 넘치게 해 보세요.
7. **칸 나누기**
   - 창 위쪽 오른쪽의 칸 나누기 단추를 누르면 메뉴가 열려요. 다섯 가지 중에 골라요. **⌘⌥1~5**로도 돼요.
   - 메뉴가 단추 바로 아래에 열리나요? 지금 것에 체크 표시가 있나요?
   - **Tab**으로 칸을 옮기고, 칸 사이 경계를 끌어 크기를 바꿔요.
   - **(새로)** 경계 위에 마우스를 올리면 좌우 경계에서는 좌우 화살표, 위아래 경계에서는 위아래 화살표 모양이 되나요? (두 경계가 만나는 곳은 맥에 네 방향 모양이 없어서 보통 화살표예요)
   - 지금 칸은 흰 카드로 떠 있고 다른 칸은 조금 가라앉아 보여요. 어느 칸에 있는지 바로 보이나요?
8. **보기 방식**
   - 칸마다 경로 줄 오른쪽(책갈피 앞)에 보기 방식 단추가 있어요. 누르면 그 칸에 여섯 가지(아주 큰·큰·보통·작은 아이콘, 목록, 자세히)가 나와요.
   - **(새로)** **⌘1~⌘6**으로도 바뀌어요(⌘1 아주 큰 아이콘 … ⌘5 목록, ⌘6 자세히). Finder의 ⌘1~⌘4와 차례가 달라서 헷갈리지 않는지 알려 주세요.
   - 칸마다 따로 바뀌나요? 경로 줄과 열 이름 줄 사이에 가는 선이 보이나요?
   - 아이콘 보기에서 화살표 키로 옆·위아래 칸으로 움직여 보세요.
   - **썸네일**: 사진이 많은 폴더를 아주 큰·큰·보통 아이콘으로 열어 보세요.
     - 그림 파일(jpg, png, heic 등)이 파일 아이콘 대신 사진으로 보이나요? 처음에는 파일 아이콘이었다가 곧 사진으로 바뀌어요.
     - 세로로 찍은 사진이 누워 보이거나, 사진이 찌그러져 보이지는 않나요?
     - 사진이 수백 장 든 폴더에서 빠르게 스크롤해 보세요. 스크롤이 끊기지 않나요? 멈춘 곳의 사진이 곧 채워지나요?
     - 위로 다시 올라가면 방금 본 사진은 기다리지 않고 바로 보이나요?
     - 아이콘 크기를 바꿔 보세요(보통 ↔ 큰 ↔ 아주 큰). 사진이 흐릿하지 않고 그 크기에 맞게 또렷한가요?
     - **(바뀜)** PDF·동영상·문서(docx, pages 등)도 Finder처럼 첫 장이 아이콘 모양으로 보여요. Finder의 아이콘 보기와 비슷한가요? 압축 파일·디스크 이미지처럼 썸네일을 만들 수 없는 파일은 파일 아이콘 그대로예요. 작은 아이콘·목록·자세히 보기에는 썸네일이 없어요.
     - **메모리**: 사진이 아주 많은 폴더(천 장쯤)를 큰 아이콘으로 끝까지 스크롤한 뒤, 활성 상태 보기(Activity Monitor)에서 Sakadu가 쓰는 메모리를 적어 주세요. 더 스크롤해도 계속 늘지는 않아야 해요.
9. **자동 미리 보기**
   - **(바뀜)** 그림 파일(jpg, png, heic 등), 글 파일(txt, md, csv 등), 그리고 이제 PDF·문서(docx, xlsx, pptx, pages 등)·동영상·SVG·한글(hwp) 파일을 **하나** 누르면 작은 카드가 저절로 떠요. 폴더, 압축 파일·디스크 이미지 같은 파일을 고르거나 여러 개를 고르면 뜨지 않아요.
   - **카드 자리**
     - 칸이 둘 이상이면 고른 파일이 있는 칸이 아닌 **다른 칸의 오른쪽 아래**에 떠요. 고른 파일의 이름을 가리지 않나요?
     - Tab이나 마우스로 다른 칸으로 옮겨 그 칸에서 파일을 고르면 카드도 자리를 옮기나요?
     - 칸이 하나뿐이면 그 칸의 오른쪽 아래에 떠요. 창을 좁히면 카드가 사라지는데, 이름을 가리지 않으려는 것이라 정상이에요.
   - **그림**
     - 사진이 금방 보이나요? 휴대폰으로 찍은 사진(HEIC)도 보이나요? 세로로 찍은 사진이 누워 보이지는 않나요?
     - 아주 큰 사진을 골랐을 때 창이 멈칫하지 않나요? 늦으면 카드에 '불러오는 중…'이 잠깐 보여요.
     - 화살표 키를 누른 채로 사진 여러 장을 빠르게 지나가 보세요. 버벅이지 않나요? 멈춘 곳의 사진이 맞게 뜨나요?
     - 그림으로 읽을 수 없는 파일은 카드에 '미리 볼 수 없어요'라고 나와요.
   - **글**: 앞부분 몇 줄이 보여요. 한글이 깨지지 않나요? 긴 줄은 끝이 …로 줄어요. 글이 아닌 파일(확장자만 txt인 파일)은 카드가 뜨지 않아요.
   - **(새로) 문서**: PDF는 첫 쪽, 문서는 첫 장, 동영상은 한 장면이 보여요. 첫 장이 준비된 뒤에 카드가 떠서 그림보다 조금 늦을 수 있어요. 늦게 뜨는 게 어색한가요? Finder에서 보는 첫 장과 같은가요? 첫 장을 만들 수 없는 파일은 카드가 뜨지 않아요.
   - **(새로) 한글(hwp)**: 파일이 있으면 골라 보세요. 파일 안의 미리 보기 그림이, 그림이 없으면 미리 보기 글이 보여요. 글자가 깨지지 않나요?
   - 카드 아래 줄에 이름, 종류와 크기가 있어요. 종류가 Finder에서 보는 말과 같은가요?
   - **크게 보기**: 카드 아래 줄의 화살표 단추를 누르거나, 카드를 누르거나, **스페이스**를 누르면 카드가 그 칸을 채울 만큼 커져요. 한 번 더 하면 작아져요. (카드가 없을 때의 스페이스는 맥의 훑어보기예요: 22번)
     - 크게 둔 채로 화살표 키로 다른 사진으로 옮겨 가면 계속 크게 보이나요?

    - **진행과 그만두기**: 파일 여러 개(되도록 큰 것)를 한꺼번에 붙여넣으면 위쪽 오른쪽에 '복사하는 중 · 몇 개 중 몇 개'가 보이나요? 그때 **Esc**를 누르면 하던 것만 마치고 그만둬요.
      - 복사하는 동안 창이 멈추지 않고 다른 칸을 둘러볼 수 있나요?
      - 큰 폴더 하나는 한 덩어리라 중간에 그만둘 수 없어요.
    - **되돌리기**: 붙여넣은 뒤 ⌘Z를 누르면 방금 생긴 복사본만 휴지통으로 가요. 원본과 먼저 있던 파일은 그대로여야 해요.
    - **안 되는 것**: 폴더를 자기 자신 안에 붙여넣으면 '폴더를 자기 안에 넣을 수 없어요'라고 떠요.
    - **이름을 치는 중**의 ⌘C, ⌘V는 상자 안의 글자에만 먹어야 해요.
    - 목록의 오른쪽 단추 메뉴에도 복사, 복제가 있고, 빈 곳의 메뉴에 붙여넣기가 있어요.
19. **옮기기** (**시험용 폴더 안에서만** 해 주세요: 옮길 것도 옮길 곳도 그 안에서요)
    - **잘라내서 붙여넣기**: 파일이나 폴더를 고르고 **⌘X**, 다른 폴더에서 **⌘V**.
      - ⌘X를 누른 직후에는 아무것도 바뀌지 않아요. 붙여넣을 때 옮겨져요. 원래 폴더에서 사라지고 붙여넣은 곳에 생기나요?
      - 맥의 Finder에는 파일의 ⌘X가 없어서 낯설 수 있어요. 어색한지 알려 주세요.
    - **⌥⌘V**: ⌘C로 복사해 둔 것을 복사하지 않고 옮겨요 (Finder의 '여기로 항목 이동'과 같아요). Finder에서 ⌘C 한 것을 사카두에서 ⌥⌘V로 옮겨도 되나요?
    - **같은 이름이 있는 곳으로 옮기면** 덮어쓰지 않고 번호가 붙어요(`보고서 2.docx`). 먼저 있던 파일이 그대로인지 봐 주세요.
    - **되돌리기**: 옮긴 뒤 ⌘Z를 누르면 원래 자리로 돌아가요.
    - **폴더 안을 보던 칸**: 칸 하나에서 어떤 폴더 안으로 들어가 두고, 다른 칸에서 그 폴더를 옮겨 보세요. 그 칸이 옮긴 곳의 그 폴더를 그대로 보여야 해요.
    - **안 되는 것**: 같은 폴더에 붙여넣으면 '이미 이 폴더에 있어요', 폴더를 자기 안으로 옮기면 '폴더를 자기 안에 넣을 수 없어요'라고 떠요.
    - **(바뀜)** 이제 **다른 디스크(USB, 외장 디스크, NAS)로도 옮겨요.** 32번과 33번에서 봐 주세요.
    - 목록의 오른쪽 단추 메뉴에도 잘라내기가 있어요.
20. **끌어서 놓기** (개발자 쪽에서는 실제로 끌어 볼 수 없었어요. **시험용 폴더 안에서만** 해 주세요)
    - **사카두 안에서**
      - 파일을 눌러 고른 뒤, 누른 채로 끌어 보세요. 파일 아이콘이 마우스를 따라오나요?
      - **다른 칸**으로 끌면 그 칸에 테두리가 생기나요? 놓으면 그 칸의 폴더로 옮겨지나요?
      - **폴더 줄** 위로 끌면 그 줄이 강조되나요? 놓으면 그 폴더 안으로 들어가나요?
      - **사이드바의 폴더 줄**(고정한 곳, 홈·문서 같은 곳) 위에도 놓을 수 있어요.
      - **(새로)** **탭 위**에도 놓을 수 있어요. 지금 보고 있지 않은 탭 위로 끌면 그 탭이 마우스를 올린 모양이 되고 칸에 테두리가 생기나요? 놓으면 그 탭의 폴더로 가나요?
      - 여러 개를 고른 뒤 그중 하나를 누르고 끌면 모두 끌려와야 해요. 끌지 않고 그냥 눌렀다 떼면 그 줄만 골라져요.
      - 같은 칸 안에서 조금 끌다가 빈 곳에 놓으면 아무 일도 없어야 해요.
      - 놓은 뒤 ⌘Z를 누르면 원래 자리로 돌아가나요?
    - **옮기기와 복사**
      - 같은 디스크 안에서는 옮겨져요. **⌥(option)를 누른 채** 끌면 복사돼요: 마우스에 초록 더하기 표시가 붙나요?
      - USB나 외장 디스크가 있으면: 다른 디스크로 끌면 복사돼요(원본이 남아요). 더하기 표시가 붙나요?
      - **(바뀜)** **⌘를 누른 채** 다른 디스크로 끌면 옮겨져요: 복사한 뒤 원본은 휴지통으로 가요(32번).
      - **⌥⌘를 함께 누른 채** 끌면(Finder에서는 가상본 만들기) 사카두는 받지 않아요: 놓일 곳이 강조되지 않고, 놓아도 **아무 일도 없어야 해요.** 파일이 옮겨지면 꼭 알려 주세요.
    - **Finder와 주고받기**
      - Finder에서 파일을 끌어 사카두의 칸에 놓아 보세요. 들어오나요?
      - 사카두에서 파일을 끌어 Finder 창이나 데스크탑에 놓아 보세요. 나가나요? 그 뒤 사카두의 목록이 맞춰지나요?
      - 사카두에서 끈 파일을 Dock의 휴지통에 놓으면 **아무 일도 없어야 해요** (지우기는 내주지 않았어요).
    - **어색한 곳**: 끌기가 너무 쉽게 시작되거나(파일을 고르려다 끌려 버림) 너무 늦게 시작되지는 않나요? 끌리는 아이콘의 자리나 크기는요?
    - 이름을 고치는 중이거나 미리 보기 카드가 떠 있을 때 끌어도 이상한 일이 없나요?
21. **폴더가 바뀌면 목록이 저절로 따라오는지** (개발자 쪽에서는 창이 뜬 채로 확인하지 못했어요)
    - 사카두와 Finder를 **나란히** 놓고 같은 시험용 폴더를 열어요. 사카두 창은 누르지 말고 Finder에서만 해 보세요.
      - Finder에서 새 폴더를 만들거나, 파일을 복제하거나(⌘D), 이름을 바꾸거나, 휴지통으로 보내면 사카두 목록이 **1초 안에** 따라오나요?
      - 사파리에서 파일을 받는 폴더(다운로드)를 사카두로 열어 두고 받아 보세요. 다 받으면 그 파일이 나타나나요?
    - **고른 것과 스크롤**: 사카두에서 몇 개를 골라 두고 아래로 스크롤해 둔 뒤 Finder에서 파일을 하나 만들어요. 고른 것과 스크롤 자리가 그대로인가요? 목록이 깜빡이거나 미리 보기 카드·썸네일이 다시 그려지지는 않나요?
    - **이름을 고치는 중**: 이름 상자를 띄워 글자를 치다가 Finder에서 그 폴더에 파일을 하나 만들어요. 치던 글자가 그대로 남고, 상자가 그 줄을 따라가나요?
    - **칸 여러 개와 탭**: 칸 두 개에 서로 다른 폴더를 열어 두면 둘 다 따라오나요? 탭을 바꿔 가려 둔 폴더는 그 탭을 다시 누를 때 맞춰져요.
    - **보던 폴더가 없어지면**: Finder에서 사카두가 보고 있는 폴더 자체를 휴지통으로 보내 보세요. 사카두에 '열 수 없어요' 안내가 뜨면 돼요(앱이 멈추거나 꺼지지 않아야 해요).
    - **USB·외장 디스크**: 사카두로 그 디스크의 폴더를 열어 둔 채 Finder에서 꺼내기(⏏)를 눌러 보세요. **꺼내져야 해요.** '사용 중이라 꺼낼 수 없습니다'가 뜨면 꼭 알려 주세요.
    - **알아 둘 것**: 파일이 생기고, 없어지고, 이름이 바뀌는 것만 따라와요. **이미 있는 파일의 크기나 고친 날짜만 바뀐 것**(받는 중인 파일이 커지는 것 등)은 바로 따라오지 않고, 사카두 창으로 돌아오거나 **⌘R**을 누르면 맞춰져요. 하위 폴더 안에서 생긴 일도 그 폴더에 들어가야 보여요.
    - 한참 켜 둔 뒤 사카두가 느려지거나 맥이 뜨거워지지는 않나요? (활성 상태 보기에서 사카두의 CPU가 가만히 있을 때 0%에 가까운지)
22. **훑어보기(Quick Look)**
    - **(바뀜)** 카드가 뜨지 않는 파일(압축 파일, 디스크 이미지 등)을 고르고 **스페이스**를 누르거나, 아무 파일에서나 **⌘Y**를 눌러요. Finder에서 스페이스를 누를 때와 같은 훑어보기 창이 뜨나요? 내용이 보이나요?
    - **(바뀜)** 이제 PDF·문서·동영상에도 카드가 떠서, 그런 파일에서 스페이스는 카드를 크게 해요. 훑어보기 창은 ⌘Y예요. 이렇게 나뉜 것이 어색한지 알려 주세요.
    - 창이 뜬 채로 **↑↓**를 누르면 사카두에서 고른 파일이 바뀌고 훑어보기 창도 따라가나요? 사카두 창을 눌러 다른 파일을 골라도 따라가나요?
    - 여러 개를 고르고 스페이스(또는 ⌘Y)를 누르면 창에서 하나씩 넘겨 볼 수 있나요?
    - 닫기: 스페이스, Esc, 창의 × 모두 닫혀야 해요. 닫은 뒤 스페이스를 누르면 다시 열리나요?
    - 폴더를 고르고 스페이스를 누르면 폴더 정보가 보여요. 빈 폴더 안에서 스페이스는 아무 일도 하지 않아요.
    - 스페이스를 누르고 있으면 창이 열렸다 닫혔다 하지 않고 한 번만 열려야 해요.
    - 인터넷에서 받은 파일도 Finder처럼 그대로 보여요 (Windows 버전은 인터넷에서 받은 파일의 미리 보기를 막지만, 맥의 훑어보기는 맥이 따로 떼어 둔 곳에서 열어서 막지 않았어요).
23. **검색** (개발자 쪽에서는 실제 맥의 홈 폴더로는 해 보지 못했어요)
    - 도구 막대 오른쪽 끝의 돋보기(또는 **⌘F**)를 누르면 그 자리에 입력 칸이 늘어나고, 사이드바 자리에 '검색 켜기' 카드가 떠요. 안내 글이 이해되나요?
    - **검색 켜기**를 누르면 홈 폴더와 응용 프로그램 폴더의 이름을 훑기 시작해요. 아래 줄의 '훑는 중 · n개'가 사라질 때까지 대략 몇 초 걸렸는지 알려 주세요. 그동안에도 찾을 수 있어요.
    - **권한 창**: 훑는 동안 데스크탑·문서·다운로드에 접근해도 되는지 맥이 물을 수 있어요. 한꺼번에 뜨지 않고 하나씩 뜨나요? 창의 설명 글이 어떻게 보이나요? 하나는 **허용 안 함**을 눌러 보세요: 아래 줄에 '읽지 못한 폴더가 있어요 · 설정에서 허용'이 뜨고, 누르면 시스템 설정이 열리나요?
    - **한글로 치면서 찾기**: '보고'처럼 한글을 칠 때 글자마다 결과가 바뀌나요? 맥에서 만든 한글 이름의 파일도 찾아지나요? 입력이 늦거나 조합이 끊기지는 않나요?
    - **고르고 열기**: ↑↓로 고르고 **Return**으로 열어요(폴더는 지금 칸에서, 파일은 그 파일의 앱으로). **⌘Return**은 지금 칸에서 그 파일이 든 폴더를 열고 그 파일을 골라 둬요. 결과를 두 번 눌러도 열려요.
    - **결과를 둔 채 일하기**: 칸을 누르면 키보드만 칸으로 가고 결과는 남아요. 입력 칸을 다시 누르거나 ⌘F를 누르면 돌아와요. **Esc**나 입력 칸 오른쪽의 ×로 닫아요.
    - **범위**: 결과 위의 '전체 · 지금 폴더'. 지금 폴더는 지금 칸의 폴더 아래만 찾아요. 라이브러리 안처럼 훑지 않는 곳을 열어 두고 고르면 '이 폴더는 검색 범위 밖이에요'가 떠요.
    - **바로 따라오는지**: 검색해 둔 채 Finder에서 그 이름의 파일을 만들거나 이름을 바꾸면 1초쯤 안에 결과가 맞춰지나요?
    - 띄어 쓰면 모두 든 이름, `|`로 나누면 그중 하나라도 든 이름을 찾아요. `/`가 든 낱말은 경로에서 찾아요 (예: `보고 문서/`).
    - **iCloud Drive**를 쓰신다면 검색을 켜기 전에 카드의 'iCloud Drive도 찾기'를 골라 보세요. 권한 창이 따로 뜰 수 있어요. iCloud에만 있고 맥에 내려받지 않은 파일이 검색 때문에 **내려받아지면 안 돼요** (Finder에서 구름 아이콘이 그대로인지).
    - **(새로)** USB·외장 디스크·NAS의 폴더도 찾게 할 수 있어요: 34번.
    - 검색을 켠 뒤 활성 상태 보기에서 사카두의 메모리가 얼마인지 알려 주세요.
    - **알아 둘 것**: 찾을 이름은 이 맥의 메모리에만 두고 저장하지 않아서, 사카두를 켤 때마다 다시 훑어요. 서명하지 않은 앱이라 **새 버전을 받을 때마다 권한 창이 다시 뜰 수 있어요.**
24. **설정**
    - 메뉴 막대의 **Sakadu → 설정…**(또는 **⌘,**)을 누르면 '설정' 창이 따로 떠요. 한 번 더 누르면 새 창이 생기지 않고 그 창이 앞으로 오나요?
    - **(바뀜)** 묶음이 **일반, 단축키, 검색, 도움말, 정보**로 늘었어요. 창 안에서 스크롤돼요.
    - **일반**: '숨김 항목 보기'와 '자동 미리 보기' 스위치를 바꾸면 본 창이 바로 바뀌나요? 본 창에서 **⌘⇧.**를 누르거나 도구 막대의 눈 단추를 누르면 설정 창의 스위치도 따라 바뀌나요?
      - **(새로)** '새 탭'(25번), '모양'(13번), '메뉴 막대에서 대기'(35번), '로그인할 때 열기'(37번)도 여기 있어요.
    - **(새로) 단축키**는 28번이에요. **도움말**에는 바꾸지 않는 기본 키(⌘[ 뒤로, ⌘⌫ 휴지통 같은 것)가 모여 있어요. 메뉴 막대의 도움말(**⇧⌘/**)을 눌러도 이 창이 열려요.
    - **검색**: '이름으로 찾기'를 끄면 검색 패널이 다시 '검색 켜기' 카드로 돌아가나요? 끈 뒤 활성 상태 보기에서 사카두의 메모리가 줄어드나요? 다시 켜면 이름 옆에 '훑는 중'이 떴다가 사라지나요?
    - **iCloud Drive도 찾기**를 켜고 끌 수 있어요. 검색이 켜져 있으면 바꾸는 즉시 다시 훑어요.

    - **⌘Q**나 아이콘 메뉴의 '끝내기'는 정말 끝내요. 스위치를 끄면 아이콘이 사라지나요?
36. **어디서든 찾기** (새로. 다른 앱을 앞에 두고 해 주세요)
    - 설정 → 단축키 → **어디서든 찾기** 줄에 지금 쓰는 키가 보여요. 정하지 않았으면 '자동 (⌃⌥Space)'처럼 비어 있는 키를 골라 둬요. 어떤 키가 보이는지 알려 주세요.
    - 사파리나 Finder를 앞에 두고 그 키를 눌러요. 사카두가 앞으로 나오고 검색 칸이 열리나요? 창을 닫아 둔 대기 상태(35번)에서도 되나요?
    - 그 키가 맥이나 다른 앱의 단축키와 겹치지 않나요? 맥의 입력 소스 전환 키(⌃Space, ⌃⌥Space 등)를 쓰신다면 **한/영 전환이 그대로 되는지** 꼭 봐 주세요. (⌥⌘Space는 보통 Finder 검색 창이라 사카두가 건너뛰어요)
    - 줄의 단추를 눌러 직접 키를 정해 보세요(28번처럼). 한글 입력 상태에서도 그 키가 먹나요?
37. **로그인할 때 열기** (새로)
    - 설정 → 일반 → **로그인할 때 열기**를 켜요. '로그인 항목에서 허용해야 해요'와 **설정에서 허용** 단추가 나오면 눌러서, 시스템 설정 → 일반 → 로그인 항목에서 사카두를 허용해요. 어떤 창과 안내가 떴는지 알려 주세요.
    - 로그아웃했다가 다시 로그인하면 사카두가 열리나요?
    - 메뉴 막대 대기(35번)도 켜 두면, 로그인할 때 창 없이 메뉴 막대 아이콘으로만 시작하나요?
    - 끄면 시스템 설정의 로그인 항목에서도 빠지나요?
    - 서명하지 않은 앱이라 등록이 안 될 수도 있어요. 그러면 뜬 알림을 그대로 적어 주세요.
38. **Finder에서 사카두로 열기** (새로)
    - 맥은 Finder를 다른 앱으로 바꿀 수 없어서, Finder에서 사카두로 보내는 길을 셋 넣었어요. 사카두를 한 번 연 뒤에 해 보세요.
    - Finder에서 폴더를 오른쪽 단추로 눌러 **다음으로 열기**에 Sakadu가 있나요? 고르면 사카두에 새 탭으로 열리나요?
    - 폴더나 파일을 오른쪽 단추로 눌러 **서비스 → Sakadu에서 열기**가 있나요? 파일이면 그 파일이 든 폴더가 새 탭으로 열리고 그 파일이 골라져 있나요?
    - 폴더를 Dock의 사카두 아이콘에 끌어 놓아도 열리나요?
    - 사카두를 끝낸 상태에서도 해 보세요. 사카두가 켜지면서 그 폴더가 열리나요?
    - 메뉴에 보이지 않으면, 로그아웃했다가 다시 로그인한 뒤에도 없는지 알려 주세요.

## 4. 아직 없는 것 (안 되는 게 정상이에요)

- 탭을 끌어 다른 칸이나 다른 자리로 옮기기 (탭 위에 파일을 놓는 것은 돼요)
- 바로 지우기(휴지통을 거치지 않는 삭제), 되돌린 것을 다시 하기(⇧⌘Z)
- 목록 메뉴의 Finder 줄: 훑어보기, 다음으로 열기, 압축하기, 정보 가져오기, 공유, 태그 (메뉴에는 열기·Finder에서 보기·이름 바꾸기·잘라내기·복사·복제·휴지통이 있어요)
- Finder 대신 기본 파일 관리자로 쓰기 (맥이 허락하지 않아요. 38번의 세 길로 열어요)
- 글자 크기 바꾸기, 사이드바 목록으로 가는 키(Windows의 Ctrl+B)
- 시작 화면에서 글자로 거르기, 시작 화면 항목의 오른쪽 단추 메뉴, 디스크 남은 용량 말풍선
- 즐겨찾기 그룹의 접기·펼치기, 그룹 머리 메뉴의 위로·아래로 이동 (끌어서 옮겨요)
- 파일 내용 검색, 검색 결과의 미리 보기 카드
- 문서 카드의 '불러오는 중…' (첫 장이 준비되면 떠요). 미리 보기 창의 글은 줄을 바꾸지 않고 끝을 …로 줄여요
- 압축 파일 안의 압축 파일은 들어가지 않고 꺼내서 열어요. 큰 압축 파일은 폴더를 열 때마다 처음부터 다시 읽어서 느릴 수 있어요
- 두 경계가 만나는 곳의 네 방향 마우스 모양 (맥에 없어서 보통 화살표예요)
- 이미 있는 파일의 크기·고친 날짜만 바뀐 것은 바로 따라오지 않아요 (사카두 창으로 돌아올 때와 **⌘R**을 누를 때 맞춰져요). 네트워크 폴더(NAS)에서 다른 컴퓨터가 바꾼 것도 그럴 수 있어요

## 5. 결과 보내기

- 이상한 곳은 화면 녹화(**⌘⇧5** → 선택 부분 기록)나 스크린샷으로 보내 주세요.
- 한 줄씩 메모: **몇 번 · 어디서 · 무엇을 했더니 · 어떻게 됐는지**
- 맥 정보: Apple 메뉴 → 이 Mac에 관하여의 macOS 버전, 그리고 칩(Apple M… 또는 Intel)
- **(새로) 사카두 판**: 받은 zip의 이름(`Sakadu-v…-macos.zip`)이나 설정 → 정보의 'Sakadu …' 번호. 맥 미리 보기를 받았다면 릴리즈 글에 적힌 날짜와 커밋도요.
- **멈추거나 꺼지면 로그를 부탁해요.**
  1. 사카두를 끝내요(메뉴 막대 대기 중이면 아이콘 → 끝내기).
  2. 터미널을 열고 다음처럼 실행해요(응용 프로그램 폴더에 옮겼을 때).
     ```
     /Applications/Sakadu.app/Contents/MacOS/sakadu-mac --log
     ```
  3. 같은 일을 다시 해 본 뒤 앱을 끝내요.
  4. `open $TMPDIR`로 열리는 폴더의 `sakadu.log`를 보내 주세요.
